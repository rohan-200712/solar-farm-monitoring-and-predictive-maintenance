# Solar Farm Monitoring & Predictive Maintenance Platform (Web App)

A centralized full-stack MERN IoT web application for solar photovoltaic plant monitoring, fault detection, and energy analytics.

---

## 🚀 Quick Start (Running Locally as a Web App)

### 1. Prerequisites
- **Node.js** (v18 or higher) — [Download Node.js](https://nodejs.org/)

### 2. Installation
Open your terminal in this project folder:
```bash
npm install
```

### 3. Start the Web App
```bash
npm run dev
```

### 4. Open in Your Web Browser
Navigate to:
👉 **[http://localhost:3000](http://localhost:3000)**

## ⚡ Features
- **Real-Time SCADA Telemetry**: WebSocket live updates every 4 seconds (Inverters, PV Panels, Irradiance, Temperature).
- **Embedded In-Memory Database**: Works out-of-the-box without needing to install external databases.
- **Predictive Maintenance**: Real-time risk anomaly scoring and fault generation tools.
- **Role-Based Access Control**: Operator, Technician, and Administrator views.
- **Responsive Web Design**: Optimized for desktop browsers, tablets, and mobile devices.
